   python run.py

5. Access at:
   http://localhost:5000

==================================================
AI FRAUD DETECTION DETAILS
==================================================

Algorithm: Isolation Forest
Contamination Rate: 10%
Features Analyzed:
1. Vote time hour (0-23)
2. Time spent on voting page (seconds)
3. Same IP vote count
4. User total vote count
5. Time between consecutive votes
6. Unusual hour detection (late night)

Detection Triggers:
- Duplicate voting attempts
- Multiple votes from same IP (>5)
- Very fast voting (<5 seconds)
- Voting during unusual hours
- Anomalous ML score
